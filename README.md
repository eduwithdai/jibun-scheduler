# じぶんスケジューラー（きょうの じかんわり）

こどもむけの、1日のよていを かんたんに つくれる Web アプリです。
HTML 1ファイルだけで うごきます。よていは ブラウザの localStorage に ほぞんされます。

## つかいかた

公開ページ: https://eduwithdai.github.io/jibun-scheduler/

ローカルで つかう場合は `index.html` を ブラウザで ひらくだけです。

## よみあげ

ブラウザの音声合成（Web Speech API）で よみあげます。ネットにはつなぎません。

- かもくカードを えらぶと、その かもく名を よみます
- コマに いれると「いちじかんめは、こくご」のように よみます
- うまっているコマを タップすると、もういちど よみます
- 📢 **よみあげ** … その日の よていを さいしょから ぜんぶ よみます（もういちど押すと とまります）
- 🔊 **おと** … よみあげの オン／オフ。せっていは ブラウザに ほぞんされます

音声合成に対応していないブラウザでは、この2つのボタンは表示されません。

## かもくカードの せってい

⚙ **せってい** ボタンを **ながおし（約1びょう）** すると ひらきます。
こどもが さわっても すぐ開かないように、1回おしただけでは ひらきません。

せってい画面で、かもくカードごとに つぎのことが できます。

| できること | やりかた |
|---|---|
| ならびかえ | ▲ ▼ でうごかす |
| もじを かえる | ますに かきこむ。**かいぎょう すると 2ぎょう**になる |
| えを かえる | 🖼 え → タブレットのなかの 画像をえらぶ |
| おとを かえる | 🔊 おと → タブレットのなかの 音声をえらぶ |
| きいてみる | ▶ きく |
| もとにもどす | ↩ もどす（そのカードの もじ・え・おと だけ） |

「けす」カードは いつも いちばん うしろです。ならびかえには 入りません。

### どこに ほぞんされるか

せっていは **その タブレット（ブラウザ）のなかだけ** に のこります。
サーバーには おくられません。ほかの タブレットには うつりません。

- もじと ならびじゅん → localStorage
- えと おと → IndexedDB（画像や音声は大きいので、こちらに そのまま入れる）

ブラウザの データを けすと、せっていも きえます。
