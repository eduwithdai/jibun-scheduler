# じぶんスケジューラー（きょうの じかんわり）

こどもむけの、1日のよていを かんたんに つくれる Web アプリです。
HTML 1ファイルだけで うごきます。よていは ブラウザの localStorage に ほぞんされます。

## つかいかた

公開ページ: https://eduwithdai.github.io/jibun-scheduler/

ローカルで つかう場合は `index.html` を ブラウザで ひらくだけです。

## よみあげ

ブラウザの音声合成（Web Speech API）で よみあげます。ネットにはつなぎません。

- かもくカードを えらぶと、その かもく名を よみます
- コマに いれると「いちじかんめは、こくご」のように よみます
- うまっているコマを タップすると、もういちど よみます
- 📢 **よみあげ** … その日の よていを さいしょから ぜんぶ よみます（もういちど押すと とまります）
- 🔊 **おと** … よみあげの オン／オフ。せっていは ブラウザに ほぞんされます

音声合成に対応していないブラウザでは、この2つのボタンは表示されません。
