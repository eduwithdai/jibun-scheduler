# よみあげ音声 ろくおんリスト

このフォルダに音声ファイルを置くと、ブラウザの合成音声のかわりに
その音声が再生されます。ファイルが無いものは、これまでどおり
合成音声で読み上げます（両方のまぜこぜでも動きます）。

## ファイルの仕様

| 項目 | 推奨 |
|---|---|
| 形式 | **MP3**（iPad・Windows・Android すべてで再生できる） |
| チャンネル | モノラル |
| ビットレート | 96〜128 kbps（声だけなので十分） |
| 前後の無音 | **できるだけ切る**（つなげて再生するため、無音があると間延びする） |
| 音量 | 全ファイルで揃える（マイクとの距離を一定に） |
| ファイル名 | 下の表のとおり（半角英数字。日本語名は不具合のもとなので使わない） |

「時限」＋「教科」の2ファイルを続けて再生して
「いちじかんめは、こくご」という1文にします。
そのため **時限のファイルは「〜は、」まで含めて**読んでください。

## ろくおんのコツ

- **ゆっくり、はっきり**。ふだんの会話より少し遅いくらい。
- 時限ファイルは**文の途中**なので、語尾を下げきらない。
- 教科ファイルは**単独で完結**するので、ふつうに言い切る。
- 1ファイルずつ録るより、**続けて録音して後から切り分ける**ほうが
  声の調子と音量が揃います。
- 教科を増やすときは、`images/` に画像を、ここに同じ名前の音声を
  足してください。
